# Data Flow Architecture

## Important: All Data Comes From The Agent (Van)

**All metrics displayed in the dashboard originate from the uptime-agent running in each van, NOT from the main dashboard PC system.**

## Data Flow Path

```
┌─────────────────┐
│  Agent (Van)    │  ← Generates all metrics (speedtest, location, interfaces, etc.)
│  uptime-agent   │
└────────┬────────┘
         │
         │ Exposes /metrics endpoint
         │ (Prometheus format)
         │
         ▼
┌─────────────────┐
│    ngrok        │  ← Tunnels agent's /metrics endpoint
│  (tunnel)       │
└────────┬────────┘
         │
         │ HTTPS: https://fumelike-anabel-sandier.ngrok-free.dev/metrics
         │
         ▼
┌─────────────────┐
│  prometheus-    │  ← Adds ngrok-skip-browser-warning header
│  proxy          │
└────────┬────────┘
         │
         │ HTTP: http://prometheus-proxy:8081/metrics
         │
         ▼
┌─────────────────┐
│  Prometheus     │  ← Scrapes metrics every 15 seconds
│  (Time Series   │     Stores historical data
│   Database)     │
└────────┬────────┘
         │
         │ PromQL queries via /api/v1/query
         │
         ▼
┌─────────────────┐
│  Backend API    │  ← Queries Prometheus for metrics
│  /api/metrics/* │     - /api/metrics/speedtest
│                  │     - /api/metrics/interfaces
│                  │     - /api/metrics/current
│                  │     - /api/metrics/location
└────────┬────────┘
         │
         │ REST API calls with JWT auth
         │
         ▼
┌─────────────────┐
│  Frontend       │  ← Displays data in dashboard
│  (React App)    │     - NetworkSpeedSection
│  Port 5173      │     - InterfaceSpeedSection
│                  │     - LocationSection
│                  │     - NetworkHealthSection
└─────────────────┘
```

## Metrics Source

All metrics are generated by the **uptime-agent** running in each van:

1. **Speedtest Metrics** (`van_speedtest_*`)
   - Generated by: Agent running speedtest on van's network
   - Exposed at: `/metrics` endpoint on agent
   - Scraped by: Prometheus every 15 seconds

2. **Location Metrics** (`van_location_*`)
   - Generated by: Agent detecting van's location via geolocation API
   - Exposed at: `/metrics` endpoint on agent
   - Scraped by: Prometheus every 15 seconds

3. **Interface Bandwidth** (`van_interface_*`)
   - Generated by: Agent monitoring network interfaces (via OPNsense API or direct monitoring)
   - Exposed at: `/metrics` endpoint on agent
   - Scraped by: Prometheus every 15 seconds

4. **Device Status** (Uptime Kuma devices)
   - Generated by: Agent polling Uptime Kuma API
   - Sent via: Socket.IO to backend
   - Stored in: SQLite database

## No Local Data Generation

**The main dashboard system does NOT generate any metrics locally.** It only:
- Scrapes metrics from agents via Prometheus
- Stores device status from Socket.IO events
- Queries and displays the data

## Verification

To verify data is coming from the agent:

1. **Check Prometheus targets:**
   ```bash
   docker exec dashboard-prometheus wget -qO- "http://localhost:9090/api/v1/targets"
   ```
   Should show target pointing to agent's ngrok URL.

2. **Check Prometheus metrics:**
   ```bash
   docker exec dashboard-prometheus wget -qO- "http://localhost:9090/api/v1/query?query=van_speedtest_download_mbps{van_id=\"van1\"}"
   ```
   Should return data with `van_id="van1"` label from agent.

3. **Check backend API:**
   ```bash
   curl -H "Authorization: Bearer YOUR_TOKEN" http://localhost:4000/api/metrics/current?vanId=van1
   ```
   Should return data queried from Prometheus (which scraped from agent).

4. **Check agent metrics directly:**
   ```bash
   curl -H "ngrok-skip-browser-warning: true" https://fumelike-anabel-sandier.ngrok-free.dev/metrics | grep van_speedtest
   ```
   Should show metrics generated by the agent.
